# Elo — O elo do cuidado

Landing page do **Elo**, o prontuário digital de cuidado domiciliar (home care):
rotina de plantão, checklist, passagem de turno, métricas, placar da equipe,
disponibilidade do serviço e segurança (acesso por papel + auditoria).

Página estática (`index.html`) com um herói 3D em Three.js — dois anéis
entrelaçados representando o "elo" entre cada plantão.
